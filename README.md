# 🏋️ Core Push Pro

**Core Push Pro** est une application web conçue pour le suivi et l'entraînement ciblé des séries de gainage (*Core*) et de pompes (*Push*).

---

## 🚀 Fonctionnalités
- ⏱️ **Timer & Interval Training** : Gestion des temps de préparation, de travail et de repos.
- 🔢 **Compteur de répétitions** : Suivi interactif des pompes et exercices.
- 📊 **Statistiques & Suivi** : Visualisation des performances et séries au fil du temps.
- 📱 **Interface responsive** : Optimisée pour un usage mobile et desktop.

---

## 🛠️ Stack Technique
- **Frontend** : HTML5, CSS3, JavaScript (Vanilla / Chart.js)
- **Hébergement & CI/CD** : [Netlify](https://www.netlify.com/) (Déploiement continu via GitHub)
- **Backend & Services** : [Firebase](https://firebase.google.com/) (Firestore, Auth, Functions)

---

## 📦 Installation & Déploiement

### Déploiement automatique (Netlify)
Chaque `push` effectué sur la branche `main` du dépôt GitHub déclenche automatiquement un nouveau build et déploiement sur Netlify.

### Configuration des variables d'environnement
Pensez à ajouter vos identifiants Firebase dans le panneau de configuration Netlify :
- `Site configuration` > `Environment variables`
